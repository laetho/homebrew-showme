# homebrew-showme

Homebrew tap and public binary releases for `showme`.

## Install

```sh
brew tap laetho/showme
brew install showme
```

Or install the formula directly:

```sh
brew install laetho/showme/showme
```

The formula supports macOS and Linux on Intel/AMD64 and ARM64. Windows archives are available from this repository's [releases](https://github.com/laetho/homebrew-showme/releases).

## Upgrade

```sh
brew update
brew upgrade showme
```
